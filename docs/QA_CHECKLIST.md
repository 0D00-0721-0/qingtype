# 安装、更新与模型人工验收清单

本清单用于真实 Mac 上的人工验收。自动化测试只能覆盖临时目录中的事务逻辑，
不能替代真实系统输入源、真实键盘输入和真实网络。

准备：记录当前版本（应用、输入法、模型）和 `~/Library/QingType` 的大小；
建议先做一次完整备份（设置 → 自动学习 → 备份，或直接复制整个目录）。

## 安装与重复安装

- [ ] 第一次安装：未安装状态点「安装并启用清言」，完成后显示已安装，并可输入中文
- [ ] 已安装状态再次打开「开始使用」：按钮显示「已安装」，不再提供普通安装入口
- [ ] 显式点「重新安装…」并确认：只重装一次，输入短暂中断后恢复
- [ ] 连续快速点击「安装/重新安装」10 次：只产生一次安装，按钮在过程中不可点击或显示进行中
- [ ] 安装过程中切换到别的输入法：安装结束不产生第二个输入法实例或残留目录
- [ ] 安装后检查 `~/Library/Input Methods/`：只有 `QingType.app`，没有 `.qingtype-stage-*`
- [ ] 安装后检查个人词库、学习记录、设置：内容与安装前一致

## 版本与状态

- [ ] 已安装版本与安装包相同：显示已安装，不触发复制
- [ ] 安装包更新（例如 0.6.4 → 0.6.5）：显示「更新输入法」，更新后版本正确
- [ ] 用旧安装包覆盖新版本：被拒绝，提示已安装较新版本，程序未被改动
- [ ] 手动删除输入法里的 `Contents/Frameworks/librime.1.dylib`：显示「修复安装」
- [ ] 修复后输入法可正常启动，用户数据不变
- [ ] 篡改已安装程序（例如替换 `Contents/MacOS/QingType`）后重开设置：显示「修复安装」
- [ ] 连续安装/保存多次后检查 `~/Library/QingType/backups`：`install-*`、`apply-*` 各不超过 3 个
- [ ] 手动截断 `~/Library/QingType/build/qingtype_main.table.bin` 后保存并应用：自动重建成功，不需手工删除

## 失败与恢复

- [ ] 安装过程中退出清言设置：重新打开后状态正确，不显示半安装
- [ ] 安装过程中断开电源/强制关机（可恢复环境）：重启后输入法仍可用，或明确提示恢复
- [ ] 目标目录不可写：安装失败并给出原因，原程序保留
- [ ] 安装失败后重新安装：能够成功，不留下损坏状态

## 卸载

输入源仍启用时，卸载入口不应出现；先在系统设置移除清言，再执行卸载。

- [ ] 输入源仍启用：显示提示与「打开键盘设置」，没有卸载按钮
- [ ] 在系统设置移除清言后：出现卸载入口，卸载只移除程序和清言.app，`~/Library/QingType` 保留
- [ ] 卸载后重新安装：个人词库、学习记录、设置仍在
- [ ] 「删除清言用户数据」：必须在卸载之后，移到废纸篓而不是直接删除
- [ ] 卸载过程不影响其他输入法（鼠须管、系统拼音）

## 检查更新

- [ ] 已是最新版：显示「已是当前公开版本」，不出现安装按钮
- [ ] 有新版本：显示可更新版本号，安装前有确认
- [ ] 断网：显示检查失败，**不能**显示已是最新版，也不保留旧的安装按钮
- [ ] GitHub 返回 403/429：显示限流提示（含稍后重试），现有设置不变
- [ ] 连续点击「检查更新」：只发出一个请求，按钮在过程中不可用
- [ ] 服务器返回异常内容（可用代理或改 hosts 模拟）：显示解析失败，不崩溃

## 万象模型

- [ ] 第一次下载：显示进度，完成后校验并启用，可用 `--status` 或设置界面确认
- [ ] 已安装且哈希一致时再次点击：提示已是最新，不重新下载
- [ ] 删除模型 `.gram` 文件后打开设置：显示模型文件缺失或已损坏
- [ ] 下载中断（断网/退出应用/取消）：不显示已安装，临时文件被清理
- [ ] checksum 不符：拒绝安装，旧模型仍可用
- [ ] 模型更新失败：旧模型继续参与输入，设置不指向失败的新文件
- [ ] 磁盘空间不足：下载/导入失败并提示，不破坏已有模型

## 记录

每次执行后记录：日期、构建（`BuildInfo.json` 的 commit）、macOS 版本、
应用/输入法/模型版本、实际结果与截图。不要把「自动化通过」写成「人工通过」。
