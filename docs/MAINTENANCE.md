# 更新、卸载与诊断

0.6.0 起，「维护与更新」集中提供以下入口。

## 应用更新

点击「检查更新」读取本项目 GitHub Releases。检查包含预览版，并按当前处理器选择 DMG。
默认不联网检查、不自动下载；用户可开启「打开清言时检查更新」，最多每天检查一次。

只有新版本才显示安装按钮。安装前检查官方仓库地址、文件大小、SHA-256、程序身份、
签名结构以及内外版本一致性。已有 Developer ID 签名时，新版必须属于同一签名团队。
临时签名预览版的哈希来自 GitHub，不能替代 Apple 公证。

旧应用先保存到 `~/Library/QingType/backups/app-update-*/Previous.zip`，再替换正常应用。
新版启动后使用既有安装器更新输入服务并部署当前配置；失败时恢复旧程序，保留恢复清单。
原有个人词库、可选组件和学习记录继续使用，不重新下载。

请先保存设置和完成正在输入的拼音。连接配置改变时，Safari 等已运行应用可能需要
用 ⌘Q 完整退出重开。缺少写入权限时会停止并报告错误，可手动从 DMG 更新。

## 卸载

点击「卸载清言…」，默认保留 `~/Library/QingType`。
确认后先切离清言、停用输入源并退出服务，再将程序移入一个恢复文件夹，最后整体移到废纸篓。
操作失败则尝试恢复程序与输入源，并明确报告恢复是否完成。

「同时把用户数据移到废纸篓」是可选项，会包含配置、词库、模型、学习数据库与备份。
移动前取得数据独占锁，其他维护任务运行时停止卸载。恢复文件夹附有原路径清单与
`恢复说明.txt`；重新安装即可使用保留的数据。恢复用户数据时先退出清言，备份同名现有目录。
仅处理清言管理的路径，不处理 `~/Library/Rime`。

## 诊断摘要

「导出诊断摘要…」只保存到用户选择的位置，文件权限为 0600，不自动上传。
内容包括系统、引擎和清言版本，清言输入源状态，屏幕尺寸/缩放、已知应用版本及配置数量。
不含词语、拼音、快捷短语、学习记录、窗口标题或用户名路径。
用户检查后可自行在 GitHub Issues 附上。

命令行只读导出：

```sh
"$HOME/Library/Input Methods/QingType.app/Contents/MacOS/QingType" --diagnostic-report
```

隔离压力检查（默认 2,000 轮，不发送宿主键盘事件、不启用模型）：

```sh
build/QingType.app/Contents/MacOS/QingType --engine-stress-test 5000
```

该指标包含固定拼音引擎查询与候选布局，不包含真实应用的组合文本交互、按键延迟或日常长时间运行。
