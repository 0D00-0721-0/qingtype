# 真实应用测试记录模板

每次只记录一个 QingType 构建、一个应用版本和一个控件；同一应用的其他控件或新构建另建记录。先阅读 [兼容性验收矩阵](COMPATIBILITY.md) 的状态约定和每列步骤。不要把模板中的预期当成实测结果。

将下方模板复制到私有位置或 Issue 草稿，实际完成后再填结果。文字使用合成测试内容；截图和日志应去掉账号、聊天内容、路径、个人词条、学习数据及其他私人信息。不要提交数据库、用户配置或模型。

先按 [固定包验收流程](ACCEPTANCE_BUILD_VALIDATION.md) 生成测试前后的只读快照。两次 artifactId、DMG 摘要与构建必须一致；途中输入服务更换则明确记录。快照只验证程序身份，不能代替真人结果。
