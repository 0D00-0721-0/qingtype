## 大文件与取消：PASS

使用带有非零首尾标记的合成稀疏文件，不使用真实模型或用户数据。

- 64、256、1024 MiB 的 SHA-256 与按已知块独立计算的期望摘要相同。各文件用新子进程测量，避免较早的高峰掩盖后续增长。
- 每个子进程的 `ru_maxrss` 峰值增量必须小于 64 MiB；1 GiB 与 64 MiB 的增量差必须小于 32 MiB。本机单独专项约 1.6 MiB。这些是回归阈值，不是输入服务总内存上限。
- 一个新进程连续校验 256 MiB 八次，摘要一致且峰值有界，每次返回后目标文件描述符均为零。
- 开始前取消不打开目标文件；读取中取消通过同进程文件描述符及文件偏移确认已经开始读取，不再假定延时足以触发。五次取消都抛出取消错误并关闭目标句柄；之后完整校验 1 GiB 仍返回正确摘要，峰值有界。
- 内存释放的证据是描述符关闭、重复/取消后峰值有界和后续校验成功，不要求系统分配器立即把 RSS 降到启动值。

**退化验证**：只在忽略的临时源码副本中移除逐块 autoreleasepool；256 MiB 文件的摘要仍正确，但峰值增量达到 270,172,160 字节，超过新测试的 64 MiB 上限。证明保护能检出曾出现的整文件滞留；正式源码和运行服务未注入该退化。

## 隔离连续引擎运行

干净构建 `48f8f2e` 使用临时用户目录、禁用学习、工厂词库且不加载可选模型。测试不向 TextEdit 或其他宿主发送键盘事件，不操作系统输入源。每轮合成输入、部分退格及候选更新，再选择短词或取消长组合；选择结果必须与引擎提交的 Unicode 文本一致。

```sh
build/QingType.app/Contents/MacOS/QingType \
  --engine-stress-test 100 --minimum-seconds 300 > build/memory-engine-5min.log 2>&1
```

最短时长从 100 轮预热后计算；测量循环按 10 ms 间隔让出 CPU。平均耗时包含引擎及候选更新、编辑、提交/取消，P95 用最多 8,192 个均匀蓄水池样本估计。与旧 `workloadVersion` 的数值不直接比较，更不能当作真实宿主的按键延迟。

**PASS**：实际持续 300.04 秒、15,061 轮，验证 12,049 次选词提交、2,151 次编辑和 3,012 次取消。预热后 RSS 365.27 MiB，结束 366.80 MiB（增加 1.53 MiB），期间观测最高 375.05 MiB；共 296 个内存点，计时样本达到 8,192 上限后保持有界。

**PASS**：独立采样器对该隔离进程另采样 180.01 秒、37 点，物理占用 24.97 → 28.03 MiB，范围 24.97–28.38 MiB。该三分钟窗口在五分钟循环内部，不冒充全程物理占用；RSS 与物理占用是不同指标。

运行期间也在执行完整回归，延迟数值只用于记录该负载环境。以上结果是这次隔离负载的实测，不能证明所有场景长期无泄漏。

## 实际输入服务的两小时观测：按用户要求取消

正式试采从 **2026-10-29 18:03:39（Asia/Shanghai）** 开始，原目标 7,200 秒、15 秒间隔；用户随后表示无需观测，已停止采样并删除后续自动复核。固定为本机已安装且干净的 `05c1bd5` / 0.6.5、PID 47899；该服务没有为了本轮诊断重新安装或重启。隔离引擎运行使用另一份干净构建 `48f8f2e`，两组结果分别记录来源，不混称同一包。

```sh
python3 scripts/monitor-memory.py --pid <已确认的清言服务PID> \
  --duration-seconds 7200 --interval-seconds 15 \
  --output build/<新的观测目录>
```

工具从 SDK 的 `RUSAGE_INFO_V0` 读取 `ri_resident_size` 和 `ri_phys_footprint`，单位均为字节。它不采集按键、组合文字、候选、剪贴板、窗口标题或词条，不联网，不停止进程，也不修改用户目录。辅助 CPU 计数没有纳入报告；开发期试采目录 `memory-service-2h` 已中断，不用于正式两小时结论。

- 每次读数核对进程 UUID/启动标识及程序路径；程序/构建文件改变、PID 复用或退出即停止，未知值不记为零。
- 使用单调时钟记录实际时长，同时检查采样间隔。长缺口、中断及查询失败保存不完整报告，不能算连续观测通过。
- 输出目录 0700，JSON/JSONL 0600；拒绝覆盖已有报告，最多 10,000 个样本。原始报告留在忽略的 `build/`。
- `complete=true` 只表示该时长内采样完整。`inputActivityVerified=false`、`memoryVerdict=not_assessed` 明确表示没有证明真人输入，也没有自动宣布不存在泄漏。

**SKIPPED / 用户取消**：正式目录 `build/memory-service-2h-final/` 保留约 19.89 分钟、80 个点的试采，最终 `complete=false`、`reason=interrupted`。该记录未满两小时，不算长时验收通过，也不再等待其完成。20:10 一次复核已删除；停止的是采样程序，输入服务 PID 47899 继续运行。
