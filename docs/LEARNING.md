# 自动学习与学习数据

清言沿用 Rime 的用户词典机制。选择候选后，引擎记录用词习惯并参与后续排序。
万象仍是已选择的本地语言模型；学习记录独立保存，不会修改模型文件。

## 使用

设置侧栏的「自动学习」提供开关、备份、导出、合并恢复、重置和清除入口。
开关修改后点击「保存并应用」。关闭时不使用或新增学习记录，已有记录保留；
再次开启后可以继续使用原来的记录。

全拼简体、全拼繁体与小鹤共享 `qingtype_main.userdb`；雾凇使用
`rime_ice.userdb`。保持既有数据库名称，不随个人词库重建或模型更换改名。
删除固定个人词条后，先前学习的同名词仍可能出现。

## 备份与恢复

- 「立即备份」生成本机备份，位于 `~/Library/QingType/learning-backups`。
- 「导出最近备份」可另存 `.qinglearning` 文件。
- 「恢复备份」先检查格式、数据库身份、记录数值与 SHA-256，再用 Rime 的
  原生快照接口在隔离工作目录合并，验证数据库能重新读取后再替换。
- 恢复会保留现有历史并按 Rime 规则合并；恢复前自动备份。反复导入同一备份
  使用 Rime 的合并规则，不直接累加同一份记录。
- 备份同时纳入清言目录内的本地同步快照，避免重置时遗失尚未合并的历史。
  正常备份不把这些历史写入正在使用的数据库。

`.qinglearning` 是版本化的 JSON 容器，内含 Rime 文本快照、数据库名称和摘要。
它不是加密文件。本机备份仅当前用户可读写；导出位置的访问和同步由用户管理。
备份时会短暂退出输入服务，只读取已关闭数据库的私有副本；操作结束后恢复原有服务。

## 重置与隐私

学习数据包含选择过的词组、拼音编码、使用次数与排序权重，可能包含姓名、地址
和专业术语等私人内容。清言的学习管理功能不上传这些数据，备份也应视为私人文件。

- 「重置学习记录」清除当前数据库和本地同步快照，保留重置前的学习备份。
- 「清除记录及本机备份」经确认后清除所有方案的当前数据库、本地同步快照
  和清言学习备份。手动导出的副本需自行删除。
- 个人词库、导入词库、快捷短语、设置和模型不属于学习清除目标。
- 如果自动学习仍开启，后续选词会重新产生学习记录。需要停止积累时先关闭并保存。
- 自定义外部同步目录不在清言的写入范围内。检测到这类设置时，重置与清除会停止，
  提示用户先处理同步设置；不会改写 `~/Library/Rime` 或外部同步文件。

操作使用数据库互斥和移动恢复事务。失败会恢复原文件；恢复未确认或旧数据清理
失败时保留恢复目录并停止输入服务，不报告成功。恢复目录中的 `recovery.json`
记录原相对路径，处理前请保留目录内容。

## 可重复验证

开发环境执行：

```sh
./scripts/build-dev.sh
QINGTYPE_RIME_ICE_TEST_PACKAGE=/path/to/full/rime-ice ./scripts/test.sh
```

学习引擎测试使用临时目录和合成词条，开启真实用户词典。先选择低权重候选，
观察排序变化，再验证全新进程、个人词库 CSV 导入/删除、方案切换与重新部署。
随后实际重置并恢复备份，检查候选行为；也覆盖关闭时无新记录、本地同步历史、
恢复保留备份后新增的学习、隐私清除与数据边界。提供完整雾凇资源时同时验证雾凇。

可额外用 `QINGTYPE_LEARNING_TEST_MODEL=/path/to/model.gram` 执行
`build/QingType.app/Contents/MacOS/QingType --learning-engine-test`，验证模型共存。
测试不会访问用户正在使用的学习数据库。

真实应用人工验收：

| 操作 | 预期 |
| --- | --- |
| 在普通输入框输入同一拼音，反复选择一个原本靠后的词 | 后续候选排序向前变化 |
| 完整重启清言输入服务后再次输入 | 学习结果保留 |
| 新增/导入个人词条，保存应用后输入同一拼音 | 原来的学习结果保留 |
| 备份学习数据，在愿意重置的测试环境重置并恢复 | 重置消除学习优势，恢复后重新出现 |
| 关闭自动学习并保存，继续选词，再次开启 | 关闭期间不产生新学习，原记录仍可用 |

内部引擎验证与人工应用验收分别记录在 `VALIDATION.md` / `PROGRESS.md`。
开发过程中不得用真实用户记录演练重置或清除。

上游依据：[Rime 用户词典说明](https://github.com/rime/home/wiki/UserGuide)、
[原生备份与恢复实现](https://github.com/rime/librime/blob/master/src/rime/lever/user_dict_manager.cc)。
