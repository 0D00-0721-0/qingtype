# Phase 1：个人词库

在“清言设置 → 个人词库”管理词语、拼音和词频。新增或编辑弹窗点击“完成”后进入未保存状态；删除或导入也先修改编辑内容。点击页面底部的“保存并应用”后才持久保存、编译并刷新输入服务。

支持按词语/拼音搜索，按词语/拼音/词频排序；词语与规范化拼音相同的记录视为重复。相同词语的不同读音可并存。无声调拼音用空格分隔，ü / u: 会规范为 v，拼音中的撇号会规范为空格。词频为 0–1000000000 的整数，用于词表相对权重；不保证固定候选名次。

## 文本导入与导出

- CSV：逗号分隔，支持双引号字段及双引号转义。
- TSV、TXT：制表符分隔，不能用不明确的空格去猜测列。拼音内部仍用空格分隔音节。
- 支持 UTF-8（可带 BOM）与带 BOM 的 UTF-16。文件最多 10 MB，最多 100000 条记录（包含表头/注释/空行）；个人词库最多 100000 条。
- 可省略表头，默认列顺序为词语、拼音、可选词频。表头支持 `text/word/词语/词条`、`pinyin/code/拼音/编码`、`weight/frequency/词频`；可调整列顺序。空词频默认为 1000。
- 空行、# 注释行不参与导入；无效记录列出起始行号和具体原因。多行字段即使符合 CSV 转义，也会因词条不允许控制字符而被拒绝。
- 导入先预检，再选择“保留原记录”“使用导入记录”或“保留较高词频”。冲突以词语+拼音为准；文件中的后续重复记录同样按该策略处理。
- 预览显示前 500 条，计数覆盖全部；“导出检查报告”包含全部结果及错误原因。只有有效且按冲突策略保留的记录进入编辑区。
- “导出”导出当前编辑内容，包括尚未应用的修改；CSV/TSV/TXT 均可再次导入。UUID 不写入导出文件，词语/拼音/词频保留。

示例文件：`tests/fixtures/personal-dictionary-sample.csv`（同目录也有 TSV/TXT）。

## 存储、学习与失败恢复

个人词条的持久数据位于 `~/Library/QingType/settings.json` 的 `personalWords` 字段。程序生成受管理的 `qingtype_personal.dict.yaml`，通过现有 `qingtype_main` 词典用于全拼和小鹤双拼。旧版本配置没有 personalWords 时按空词库加载。

固定个人词条和 Rime 自动学习是不同的数据。删除固定词条不会删除 `.userdb`；已学习的同名候选仍可能出现。0.5.0 新增学习开关、备份、合并恢复与清除入口，行为验收记录与隐私说明见 [自动学习](LEARNING.md)；内部测试与真实应用人工验收分别记录。

应用更改先停止输入服务，再保存与部署。部署明确检查词库编译结果，不能因旧编译文件仍可回答 nihao 而误报成功。失败时恢复原受管理文件并重新编译；恢复通过才恢复原输入服务。若恢复失败或检测到外部手工修改，保留备份、停止服务并显示具体错误。备份位于 `~/Library/QingType/backups/apply-<UUID>/`，`absent-files.json` 记录原本不存在的文件。

事务只覆盖生成配置名单，不删除或覆盖用户学习数据库、导入词库副本或模型文件。导入的源文件不作修改。未带 QingType 管理标记的配置仍受保护。

## 可重复验收

| 操作 | 预期 | 自动证据 / 人工状态 |
| --- | --- | --- |
| 新增“清言星河样词”，拼音 qing yan xing he yang ci，词频 50000，保存应用 | 全拼输入 qingyanxingheyangci 可以选中该词并上屏 | 隔离 Rime 已测；当前用户真实应用待确认 |
| 编辑词语、拼音与词频后应用 | 新编码生效；旧固定记录消失；身份保持 | 自动测试已测 |
| 多个同编码词调整词频 | 固定词表权重影响顺序 | 关闭学习的隔离引擎已测；不等同真实学习排序保证 |
| CSV/TSV/TXT 预检、冲突处理、导出重导 | 统计/错误行正确，字段不丢失 | 自动测试已测 |
| 重启引擎或使用小鹤双拼 | 词条仍可查询 | 隔离引擎已测 |
| 删除词条或全部个人词库后重部署 | 固定来源不再提供该词，保留学习数据库 | 自动测试已测；学习中同名词可继续出现 |
| 故意让编译失败 | 返回失败，恢复先前配置并验证恢复部署 | 配置事务模拟失败+真实引擎编译失败/恢复均已测 |
| 手工配置被外部程序修改 | 拒绝覆盖并保留备份，明确报告未完成恢复 | 自动测试已测 |

运行：`./scripts/test.sh`。个人词库专项也可运行 `build/QingType.app/Contents/MacOS/QingType --personal-dictionary-engine-test`。所有自动引擎数据位于独立临时目录，不能作为用户真实应用验收的替代。
