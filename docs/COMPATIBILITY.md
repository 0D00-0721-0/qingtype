# 真实应用兼容性验收矩阵

本表用于维护 **真实 macOS 应用中的输入体验**。更新日期：2026-10-30；当前机器为 Apple Silicon、macOS 27.0.1。测试时还应记录 QingType 构建、输入方案、应用版本、具体控件与显示环境。历史结果不能自动覆盖后续构建或整个应用。

## 状态约定

- **待验**：没有足够的当前构建、指定控件和步骤证据，或测试尚未运行。
- **通过**：在记录的构建、环境和控件中，真实组合输入完成该列全部步骤。
- **部分通过**：本列只有指定步骤具备通过证据，其余仍待验；必须写明范围，不能视为整列通过。
- **失败**：实际结果不符合预期；附复现步骤和缺陷记录。
- **受阻**：由于缺少应用、设备、权限或其他原因无法执行；记录具体原因，不算通过。
- **历史通过**：此前真实输入通过，但未在当前构建按本列完整步骤重验；引用下方历史证据。

每个格子只代表一次明确记录的应用版本和控件。不同构建或控件应新增一条记录，不覆盖原记录。回填矩阵时，在“历史真实证据”下增加编号、日期、构建、应用版本、控件及记录引用，并在相应单元格标注该编号；无证据的单元格保持待验。自动化引擎、AppKit 静态预览、系统显示已选中输入源及模拟按键不能单独证明真实应用输入通过。

### 每列如何验收

1. **基础输入**：在指定控件选择清言，输入 `nihao`，确认组合文本可见并能将中文上屏。记录实际结果，不要求不同词库的首选词完全一致。
2. **候选**：组合时确认候选窗口出现并跟随输入位置，展开与收起正常；长拼音检查候选完整显示、没有明显越界或遮挡。
3. **选词**：分别尝试空格、可见数字编号和展开后的鼠标选词，核对实际插入内容与选中的候选一致。每种方式分别记录；若控件不支持，标记受阻并说明。
4. **光标**：在已有文本中移动或点击插入点，再输入并上屏；检查候选位置和实际插入位置。记录退格、左右移动及取消组合时观察到的结果。
5. **中英切换**：按当前配置使用清言中英切换，分别验证中文组合和英文输入；再切到另一可用输入源并切回，检查仍可输入。记录使用的快捷键和状态。

不要在真实聊天中发送测试消息；终端不要执行测试文字。应用关闭或切换前保留原有未保存工作。测试结果按 [单次记录模板](COMPATIBILITY_TEST_TEMPLATE.md) 保存或摘录，截图先移除私人信息。
