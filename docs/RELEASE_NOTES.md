清言 0.6.3 预览版，仅支持 M 芯片 Mac，系统要求 macOS 14 及以上。请下载 arm64（Apple Silicon）DMG。

本版主要提高构建一致性、安装升级安全性、模型完整性和输入运行时的健壮性，保留现有词库、自动学习和候选窗口体验：

- 统一输入服务、设置应用、DMG 和预览 tag 的版本来源；构建与发行检查不一致时会失败。
- 更新输入服务前暂存、校验并备份旧程序，使用完整目录替换；注册或启用失败时尝试回滚并报告恢复结果。自动故障回滚已有隔离测试；强制退出或断电后的自动恢复尚未实现或验证。
- 模型导入、启用与普通服务启动前检查完整性；发现已选模型损坏时尝试以不加载该模型的方式启动，保留原模型和用户数据，并在设置中提示。自选模型没有可信外部摘要时无法证明源文件导入前未损坏。
- 对输入客户端和系统返回的可空值、范围与窗口位置做安全检查；增加安装、卸载、模型、引擎、学习和候选回归测试，以及真实应用测试矩阵。
- 默认保留个人词库、自动学习数据、配置和模型。清除个人数据是卸载之后独立确认的操作。

**已知限制：自动卸载可能无法完成。** 目前必须确认清言父输入源和输入模式均已停用；父输入源仍启用或状态无法确认时，卸载会在切换输入源、移动程序之前停止。在本机 macOS 27.0.1 的真实测试中，系统 API 未能可靠停用并恢复父输入源；不要强制删除正在使用的输入法。完整卸载及恢复仍待验收。

已在本机实际升级并确认清言可输入、候选窗口正常显示；此前升级后曾出现候选窗口暂时不显示、重新启动后恢复，原因尚未确定。应用兼容性、多屏、休眠与长期运行仍待逐项验收。真实用户数据未用于破坏性测试。

打开 DMG，将「清言.app」拖入 Applications，打开后点「安装并启用清言」。基础输入离线可用；雾凇与万象由用户主动选装。升级保留 `~/Library/QingType`；Safari 等已运行应用必要时用 ⌘Q 完整退出重开。

此包为临时签名、未公证预览版，首次打开可能需要按 macOS 提示到「系统设置 → 隐私与安全性」允许。GitHub 发布不表示通过 Apple 公证。附 SHA-256 文件可校验下载；构建来源见应用 Resources/BuildInfo.json。

源码、GPL-3.0、第三方来源和验收范围见仓库 README、THIRD_PARTY.md、docs/COMPATIBILITY.md。QingType-source.tar.gz 为主项目源码；运行库头文件与上游插件来源按文档中的固定 revision 获取。
