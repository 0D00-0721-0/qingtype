清言 0.6.5 预览版，仅支持 M 芯片 Mac，系统要求 macOS 14 及以上。请下载 arm64（Apple Silicon）DMG。

本版主要修复内存占用，并包含 0.6.4 的安装与更新修复：

- **修复模型校验导致的内存泄漏**：启动前校验语言模型时，1MB 分块读取的数据留在自动释放池里，导致整个模型（约 418MB）常驻堆内存。修复后同一模型下输入服务的物理占用从约 430MB 降到约 20MB，模型仍正常加载。
- 修复更新输入法时的服务与数据锁冲突：启用输入源会让 macOS 立即启动输入服务，服务占用共享数据锁，随后的配置部署拿不到独占锁。现在先部署、再注册并启用输入源。
- 安装按钮按实际状态工作：已安装且完整时不再重复复制程序，只重新部署；损坏时提供「修复安装」；已安装较新版本时拒绝覆盖；只有显式「重新安装」才执行完整替换。安装后会重新校验版本、必要文件与代码签名。
- 安装备份只保留最新 3 份事务备份；词库编译产物损坏时自动移开并重建一次，失败则还原。
- 官方万象模型更新会替换同变体的旧版本并删除其文件；雾凇更新先比较官方归档 SHA-256，已是最新时不下载、不重装。
- 模型页不再在主线程计算模型哈希，进入「语言模型」不再卡顿。
- 卸载改为引导式：macOS 27 下程序无法可靠停用输入法父输入源，现在先由用户在系统设置移除清言输入源，再执行卸载；输入源仍在时不会改动任何文件。

**已知限制：自动卸载可能无法完成。** 目前必须确认清言父输入源和输入模式均已停用；父输入源仍启用或状态无法确认时，卸载会在切换输入源、移动程序之前停止。在本机 macOS 27.0.1 的真实测试中，系统 API 未能可靠停用并恢复父输入源；不要强制删除正在使用的输入法。完整卸载及恢复仍待验收。

应用兼容性、多屏、休眠与长期运行仍待逐项验收。真实用户数据未用于破坏性测试。

打开 DMG，将「清言.app」拖入 Applications，打开后点「安装并启用清言」。基础输入离线可用；雾凇与万象由用户主动选装。升级保留 `~/Library/QingType`；Safari 等已运行应用必要时用 ⌘Q 完整退出重开。

此包为临时签名、未公证预览版，首次打开可能需要按 macOS 提示到「系统设置 → 隐私与安全性」允许。GitHub 发布不表示通过 Apple 公证。附 SHA-256 文件可校验下载；构建来源见应用 Resources/BuildInfo.json。
