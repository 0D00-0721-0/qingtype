清言 0.6.2 预览版，仅支持 M 芯片 Mac，系统要求 macOS 14 及以上。请下载 arm64（Apple Silicon）DMG。

- 万象按钮改为「检查模型更新」：相同官方哈希且本地校验通过时不重复下载、不重新部署；有新内容才下载，保留旧模型。
- 修复检查转圈：元数据整体请求限时 15 秒，检查和下载连接阶段可取消，明确显示限流与超时原因。
- 原生「维护与更新」：检查 GitHub 新版、校验下载、备份替换、失败恢复与卸载入口。默认不自动联网检查或下载。
- Rime 自动学习管理：开关、私有备份、导出、合并恢复、重置及本机清除；固定个人词库独立保留。
- 个人词库 CRUD、CSV/TSV/TXT 预检与冲突处理；雾凇完整方案和万象模型由用户在应用内主动选装。
- 候选窗保留浅灰原生风格、单窗口展开和无底部工具栏。长句展开按文字宽度排列；折叠栏按原生参考减少可见候选数量，去掉单词 180pt 限宽和整行压缩，避免长句变成省略号。数字键只对应实际可见候选。
- 增加不含词条/输入内容的诊断摘要、依赖许可文本与构建来源记录。

打开 DMG，将「清言.app」拖入 Applications，打开后点「安装并启用清言」。基础输入离线可用，不需预装鼠须管。0.4/0.5 用户可直接替换正常应用，再从「开始使用」更新输入服务；保留 ~/Library/QingType。Safari 等应用必要时用 ⌘Q 完整退出重开。

此包为临时签名、未公证预览版，首次打开可能需要按 macOS 提示到「系统设置 → 隐私与安全性」允许。GitHub 发布不表示通过 Apple 公证。附 SHA-256 文件可校验下载；构建来源见应用 Resources/BuildInfo.json。

已记录 Safari 真实输入、个人新词/学习重新部署保留，以及 QQ 搜索框输入正常。其他应用、真实多屏/休眠、长期运行和干净 Mac 的完整安装/升级/卸载仍待验收。真实用户数据未用于破坏性测试。
