清言 0.6.4 预览版，仅支持 M 芯片 Mac，系统要求 macOS 14 及以上。请下载 arm64（Apple Silicon）DMG。

本版修复 0.6.3 更新输入法时可能失败的问题：

- 修复更新输入法时的服务与数据锁冲突：启用输入源会让 macOS 立即启动输入服务，服务占用共享数据锁，随后的配置部署拿不到独占锁，导致安装回滚、部署失败、输入服务停止。现在每次部署前都会停止服务，部署成功后从正式安装路径重启。
- 调整安装顺序为先部署、再注册并启用输入源：原先先启用再部署，macOS 拉起的服务会与部署进程同时编译同一个 `build/` 目录，可能把词典表写成残片，之后每次部署都失败。现在部署期间不会有服务并发编译。
- 回滚前先停止输入服务，避免进程继续运行在事务随后会删除的临时目录中；更新失败不再留下指向已删除目录的孤儿进程。
- 已在本机 0.6.3 → 0.6.4 的真实升级中验证（升级时输入服务保持运行）：程序安装、配置部署与模型加载通过，输入法从正式路径启动，无临时目录残留；随后的重装复测同样通过，词典表大小正常、部署日志无错误。

其余行为与 0.6.3 相同：事务化安装与更新、模型完整性检查、输入运行时健壮性、自动学习与个人词库管理、原生候选窗口。安装、更新与部署失败时仍会尝试恢复程序、配置和输入源，并如实报告恢复是否完成。

**已知限制：自动卸载可能无法完成。** 目前必须确认清言父输入源和输入模式均已停用；父输入源仍启用或状态无法确认时，卸载会在切换输入源、移动程序之前停止。在本机 macOS 27.0.1 的真实测试中，系统 API 未能可靠停用并恢复父输入源；不要强制删除正在使用的输入法。完整卸载及恢复仍待验收。

应用兼容性、多屏、休眠与长期运行仍待逐项验收。真实用户数据未用于破坏性测试。

打开 DMG，将「清言.app」拖入 Applications，打开后点「安装并启用清言」。基础输入离线可用；雾凇与万象由用户主动选装。升级保留 `~/Library/QingType`；Safari 等已运行应用必要时用 ⌘Q 完整退出重开。

此包为临时签名、未公证预览版，首次打开可能需要按 macOS 提示到「系统设置 → 隐私与安全性」允许。GitHub 发布不表示通过 Apple 公证。附 SHA-256 文件可校验下载；构建来源见应用 Resources/BuildInfo.json。
